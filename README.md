## 🌟 About The Project

**Freelance-Fluxo** is a comprehensive, full-stack freelancing platform engineered to bridge the gap between skilled **developers** and **clients** seeking specialized programming services. Built on the MERN stack, it provides a seamless ecosystem for discovering talent, managing projects, and growing professionally.

> *"Empowering developers. Connecting clients. Building the future of work."*

### 🎯 Key Features

| Feature | Description |
|---|---|
| 🔐 **Secure Auth** | Email verification with JWT-based authentication |
| 💼 **Smart Job Board** | Advanced filtering and matching for programming projects |
| 🎓 **Learning Hub** | Unpaid internships, hackathons, and curated courses |
| 📜 **Certificate Upload** | Showcase professional certifications on your profile |
| 📊 **Skill Assessment** | Dynamic progress tracking with visual skill bars |
| 💬 **Real-time Chat** | Seamless client-freelancer communication |
| 🌍 **Multi-role System** | Distinct, tailored experiences for clients and freelancers |

## 🛠 Tech Stack

### Frontend
- **React.js** — Component-based UI with hooks & context API
- **Bootstrap 5** — Responsive grid system and component library
- **Axios** — Promise-based HTTP client

### Backend
- **Node.js** — Non-blocking, event-driven JavaScript runtime
- **Express.js** — Minimal and flexible web application framework
- **MongoDB** — Document-oriented NoSQL database
- **Mongoose** — Elegant MongoDB object modeling

### Dev & Security
- **JWT** — Stateless authentication tokens
- **Bcrypt** — Password hashing
- **Nodemailer** — Email verification service
- **Dotenv** — Environment variable management

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed on your system:

| Tool | Version | Download |
|---|---|---|
| Node.js | `>= 16.x` | [nodejs.org](https://nodejs.org/) |
| npm | `>= 8.x` | Bundled with Node.js |
| MongoDB | `>= 5.x` | [mongodb.com](https://www.mongodb.com/) |
| Git | Latest | [git-scm.com](https://git-scm.com/) |

```bash
# Verify your installations
node --version
npm --version
mongod --version
```

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Kalana-methsara/Freelance-Fluxo.git
cd Freelance-Fluxo
```

**2. Install backend dependencies**

```bash
cd Backend
npm install
```

**3. Install frontend dependencies**

```bash
cd ../Frontend
npm install
```

**4. Configure environment variables** *(see section below)*

**5. Start MongoDB**

```bash
# In a separate terminal
mongod
```

**6. Start the backend server**

```bash
cd Backend
npm start
# Server runs at → http://localhost:5000
```

**7. Start the frontend development server**

```bash
cd Frontend
npm start
# App opens at → http://localhost:3000
```

---

### Environment Variables

Create a `.env` file inside the `Backend/` directory:

```env
# Server
PORT=5000
NODE_ENV=development

# Database
MONGO_URI=mongodb://localhost:27017/freelance_fluxo

# Authentication
JWT_SECRET=your_super_secret_jwt_key_here
JWT_EXPIRE=7d

# Email Service (for verification)
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_email_app_password

# Frontend URL (for CORS)
CLIENT_URL=http://localhost:3000
```

> ⚠️ **Never commit your `.env` file.** It's already included in `.gitignore`.

## 💻 Usage

### Getting Started as a User

```
1. Navigate to http://localhost:3000
2. Click "Sign Up" and complete registration with your email
3. Check your inbox for the verification link and activate your account
4. Log in and explore the platform
```

### Role-Based Flows

```
👤 As a Freelancer                    💼 As a Client
─────────────────────                 ──────────────────────
• Complete your profile               • Post a project/job
• Take skill assessments              • Browse freelancer profiles
• Browse open job listings            • Review applications
• Apply to projects                   • Communicate via chat
• Upload certificates                 • Manage project milestones
• Join hackathons & courses
```

## 📡 API Reference

### Authentication Endpoints

| Method | Endpoint | Description | Auth Required |
|---|---|---|---|
| `POST` | `/api/auth/register` | Register new user | ❌ |
| `GET` | `/api/auth/verify/:token` | Verify email address | ❌ |
| `POST` | `/api/auth/login` | Login & receive JWT | ❌ |
| `POST` | `/api/auth/logout` | Invalidate session | ✅ |

### User Endpoints

| Method | Endpoint | Description | Auth Required |
|---|---|---|---|
| `GET` | `/api/users/profile` | Get current user profile | ✅ |
| `PUT` | `/api/users/profile` | Update profile | ✅ |
| `POST` | `/api/users/certificates` | Upload certificate | ✅ |

### Job Endpoints

| Method | Endpoint | Description | Auth Required |
|---|---|---|---|
| `GET` | `/api/jobs` | List all jobs | ❌ |
| `POST` | `/api/jobs` | Create a new job | ✅ |
| `GET` | `/api/jobs/:id` | Get job details | ❌ |
| `POST` | `/api/jobs/:id/apply` | Apply to a job | ✅ |

## 🤝 Contributing

Contributions are the lifeblood of the open-source community. Any contribution you make is **greatly appreciated**.

### How to Contribute

```bash
# 1. Fork the repository on GitHub

# 2. Clone your fork locally
git clone https://github.com/<your-username>/Freelance-Fluxo.git

# 3. Create a feature branch (use descriptive names)
git checkout -b feature/add-payment-gateway
# or
git checkout -b fix/job-filter-bug

# 4. Make your changes and commit with clear messages
git commit -m "feat: add Stripe payment gateway integration"

# 5. Push to your fork
git push origin feature/add-payment-gateway

# 6. Open a Pull Request on GitHub
```

### Commit Message Convention

We follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:

```
feat:     A new feature
fix:      A bug fix
docs:     Documentation changes
style:    Code formatting (no logic change)
refactor: Code restructuring
test:     Adding or updating tests
chore:    Maintenance tasks
```
